## ADR 编写规范

1. **何时写 ADR**：
   - 新增/删除微服务
   - 改变服务边界
   - 选择核心技术栈
   - 数据模型重大变更
   - 安全策略变更
   - 任何"如果做错了代价很大"的决策

2. **ADR 生命周期**：
   - 已提议 → 已接受 → 已弃用 / 已替代
   - 已接受的 ADR 不修改，只能新增替代 ADR

3. **ADR 模板**：见 [000-template.md](./000-template.md)
