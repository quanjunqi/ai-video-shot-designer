# 产品需求文档（PRD）

版本：1.0  
状态：立项评审稿  
产品：镜序 Studio

## 1. 产品定义

镜序 Studio 是一个以模型能力、工作流执行和统一资产为基础的 AIGC 创作平台。它允许用户根据当下任务，在三种创作方式之间流转：

1. **快速创作**：直接生成一组图片或一段/多段视频；
2. **工作流编排**：把多个生成步骤组织成可重复、可批量、可共享的流程；
3. **漫剧工作台**：围绕剧本、角色、场景、分镜、视频单元和审核完成专业漫剧生产。

三者不是用户等级，也不是互斥产品。一次快速生成可以被保存为工作流步骤；一个工作流结果可以成为漫剧资产；漫剧项目中的某个环节也可以调用共享工作流。

社区、资产库、任务中心、模型与算力、费用中心是跨创作方式的共享能力。

## 2. 当前产品边界

### 2.1 本期包含

- 图片快速生成；
- 视频快速生成；
- 可重复执行的工作流定义与运行；
- 步骤视图、批量视图和可选画布视图；
- 漫剧专业工作台；
- API、本地 ComfyUI、云端 GPU 三类执行线路；
- 模型能力、Adapter、工作流和部署版本管理；
- 项目、资产、任务、用量、费用、权限和审计；
- 作品与工作流的发布、收藏和 Remix。

### 2.2 本期不包含

- 不接入 `/Users/quanjunqi/depth-video-converter` 的代码和能力；
- 不建设完整非线性视频剪辑器；
- 不把无限画布作为唯一工作流交互；
- 不承诺作品成为热门或获得固定播放量；
- 不训练基础模型；
- 不允许 Agent 绕过权限、预算、审核和发布检查。

## 3. 产品原则

1. **任务导向，不给用户分等级**：入口表达“要做什么”，不表达“你是哪类用户”。
2. **简单任务保持简单**：生成几张图不要求新建复杂项目或学习节点图。
3. **工作流独立于表现形式**：底层是版本化 DAG，界面可以是步骤、表格、表单或画布。
4. **模型能力独立于执行线路**：先定义输入输出，再决定走 API、本地 ComfyUI 或云端 GPU。
5. **任何结果都可追溯**：输入、模型、工作流、参数、线路、费用和结果版本绑定。
6. **专业工作台保留专业语义**：漫剧不是通用工作流换皮。
7. **人工决定与系统执行分离**：任务成功不代表内容被采纳。
8. **一份资产，多处复用**：快速创作、工作流、漫剧和社区共享资产，但遵守可见范围。

## 5. 核心领域对象

### 5.1 通用对象

| 对象 | 定义 |
|---|---|
| Workspace | 组织或个人的工作空间与数据边界 |
| Project | 一次持续创作的业务容器 |
| Asset | 图片、视频、Prompt、角色或场景等业务资产 |
| AssetVersion | 不可变的资产版本 |
| Capability | 文生图、图生图、文生视频、图生视频等标准能力 |
| Model | 模型身份与版本 |
| Adapter | 将标准能力请求转换为某种 API 或 ComfyUI Workflow |
| ExecutionRoute | API、Local ComfyUI 或 Cloud Compute 线路 |
| Deployment | 一个可被调度的实际端点或 Runner |
| Workflow | 可编辑的工作流身份 |
| WorkflowVersion | 不可变的节点、连接和 Schema 快照 |
| WorkflowRun | 一次工作流执行 |
| Job | 一个可调度执行单元 |
| Generation | 一次模型调用的业务记录 |
| UsageRecord | Token、图片、视频秒数或 GPU 时间等用量 |
| Publication | 作品或方法的不可变公开快照 |

### 5.2 漫剧对象

```text
Shot = 导演事实，描述内容表达、调度和摄影要求
Unit = 依据目标模型约束编译出的执行单元
Take = Unit 的一次实际生成结果
```

Shot 不能因模型更换而被改写；Unit 可以针对目标模型重新编译；Take 只能被采纳或驳回，不能覆盖导演事实。

### 5.3 两套状态

系统任务状态：

```text
CREATED -> QUEUED -> DISPATCHED -> RUNNING
        -> SUCCEEDED / FAILED / CANCELLED / TIMED_OUT
```

内容决策状态：

```text
DRAFT -> CANDIDATE -> PENDING_REVIEW
      -> APPROVED / REJECTED / STALE / ADOPTED
```

## 6. 首页

首页用于恢复上下文和开始创作，不展示营销内容。

必须包含：

- 四个明确操作：生成图片、生成视频、创建工作流、进入漫剧项目；
- 最近创作及其下一步；
- 运行中、失败、待审核任务；
- 可用执行线路概况；
- 最近资产和收藏的方法；
- 全局搜索，可搜索项目、资产、模型、工作流和社区内容。

验收：首次用户不阅读说明即可开始一次图片或视频生成；已有用户能在 10 秒内恢复上一次工作。

## 7. 快速创作

### 7.1 图片生成

图片生成是直接工作台，不要求先选择模板或创建复杂流程。

布局：

- 左侧/主区域：Prompt、参考图、尺寸、数量和生成按钮；
- 高级参数折叠区：负向 Prompt、Seed、Steps、CFG、采样器、LoRA 等，按模型能力动态显示；
- 模型与线路区：模型、执行线路、预计费用和预计等待时间；
- 结果区：网格、放大、对比、下载、变体、局部重绘、保存资产；
- 历史区：同一会话的生成记录和参数回填。

关键行为：

- 默认只展示高频字段；
- 切换模型时保留兼容参数，不兼容项明确提示；
- 生成前展示本次报价；
- 用户可以选择 API、本地 ComfyUI 或云端算力；
- 结果可加入项目、作为参考图继续生成、保存为工作流。

### 7.2 视频生成

视频工作台支持文生视频和图生视频。

必须包含：

- 文本 Prompt、首帧/尾帧/参考资产；
- 时长、比例、分辨率、运动强度和候选数；
- 模型约束提示，例如只支持首帧或最大时长；
- 费用、排队时间、预计生成时间和线路健康；
- 候选结果播放、逐帧查看、下载、重做和加入项目；
- 长任务离开页面后继续执行，并在任务中心可追踪。

### 7.3 快速创作的轻项目

用户第一次点击生成时自动创建 `Quick Project`，避免先填项目表单。用户可以在结果产生后重命名、归档或升级为普通项目。

## 8. 工作流编排

### 8.1 产品定义

工作流的用户价值是“把一套做法保存下来，重复运行、批量变体、替换模型并分享”，而不是绘制节点图。

底层 WorkflowVersion 使用 DAG；产品提供多种视图，所有视图编辑同一份结构化定义：

| 视图 | 默认场景 | 价值 |
|---|---|---|
| 步骤视图 | 大多数线性或少分支流程 | 像配置任务清单一样易读 |
| 批量视图 | 多 Prompt、多素材、多参数实验 | 表格化变量和运行矩阵 |
| 画布视图 | 复杂分支、合并和依赖排查 | 查看拓扑，处理非线性结构 |
| 简化表单 | 模板使用者只需填写少量输入 | 隐藏内部步骤，降低使用成本 |

MVP 默认进入步骤视图。画布是可选视图，是否保留为高频主入口需要通过可用性测试验证。

### 8.2 步骤视图

- 顺序展示输入、生成、转换、条件、人工确认和输出步骤；
- 支持拖动排序、插入步骤、分组、并行组和条件分支；
- 每一步显示输入来源、输出去向、模型能力、线路策略和费用估算；
- 支持单步试运行、从此步继续、复用缓存和查看中间资产；
- 结构不合法时阻止发布和正式运行。

### 8.3 批量视图

- 行表示一个输入样本或 Variant；
- 列表示 Prompt 变量、参考资产、模型、Seed 和其他开放参数；
- 支持 CSV 导入、复制填充、变量组合与运行上限；
- 执行前显示任务数量、总费用区间和预计完成时间；
- 结果按行回填，失败可局部重试。

### 8.4 画布视图

- 仅在存在分支、合并或用户主动切换时突出显示；
- 画布负责关系编辑，不把所有参数永久堆在节点上；
- 参数在侧栏中编辑，中间结果在检查器查看；
- 自动布局、分组、缩放定位和错误路径高亮；
- 与步骤视图双向同步，不能形成两套工作流定义。

### 8.5 工作流模板

模板作者定义可编辑输入、默认模型、允许线路、费用上限和输出。模板使用者看到的是简化表单，必要时可“展开工作流”查看步骤。

## 9. 漫剧工作台

### 9.1 项目阶段

```text
项目设置 -> 剧本锁定 -> 导演分析 -> 视觉资产
-> 空间与调度 -> Shot / Unit 规划 -> 视频生产
-> 审核与连续性 -> 交付
```

每个阶段有明确输入、产物、校验、负责人和通过条件。Agent 可以解释和起草，但不能自动越过 Gate。

### 9.2 项目总览

- 剧集、集、场、Shot 和 Unit 完成度；
- 当前 Gate、阻塞原因、负责人和截止时间；
- 预算、实际费用、失败费用和预估余量；
- 待审核、失败任务和 stale 产物；
- 最近正式决定和上游变化影响。

### 9.3 剧本与资产

- 导入并哈希锁定剧本；
- 解析场次、事件、对白和连续性锁；
- 角色、造型、场景、道具的候选、比较、采纳与版本；
- 只有 canonical 版本可自动进入正式引用；
- 上游变更先预览影响，再局部标记下游 stale。

### 9.4 镜头与生产

- 导演建立 Shot，不绑定某一个模型；
- 系统按目标模型能力编译 Unit；
- Unit 显示引用资产、Prompt、Adapter、线路策略和成本；
- 一次生成可以产生多个 Takes；
- 审核绑定具体 Take/ArtifactVersion；
- adopted Take 的实际尾帧可成为下一 Unit 的连续性约束。

### 9.5 专业工作台与通用工作流

漫剧阶段由领域状态机管理。工作流可以作为某个阶段的执行模板，但不能替代 Shot / Unit / Take、审核和依赖失效规则。

## 10. 模型能力中心

### 10.1 能力目录

首批标准 Capability：

- `text.generate`
- `image.text_to_image`
- `image.image_to_image`
- `image.inpaint`
- `video.text_to_video`
- `video.image_to_video`
- `video.first_last_frame`
- `audio.text_to_speech`

每个 Capability 定义输入/输出 Schema、媒体限制、同步/异步特征、计量单位和安全策略。

### 10.2 模型注册

模型记录：厂商、模型族、版本、能力、参数 Schema、上下文/分辨率/时长限制、许可证、价格、弃用时间和兼容 Adapter。

同一模型可以有多个 Adapter 和执行线路；同一线路也可以承载多个模型版本。

### 10.3 模型验证

模型上线前必须通过：

- Schema 契约测试；
- 标准输入输出样本；
- 错误码和重试分类；
- 价格和计量校验；
- 内容安全和许可证检查；
- 性能、成功率和输出文件完整性测试。

## 11. 算力与执行中心

### 11.1 API 线路

支持官方 API 和合规聚合服务。管理员配置 Endpoint、Secret、区域、限流、价格和 Webhook；用户只看到能力、模型、价格、可用性和数据策略。

### 11.2 本地 ComfyUI

用户安装轻量 Local Agent，由 Agent 主动连接平台，不要求公网暴露 ComfyUI。

产品必须支持：

- 设备配对、在线状态和版本；
- ComfyUI 地址和队列检测；
- Workflow JSON 导入与参数映射；
- 节点/自定义节点依赖检查；
- 模型和 LoRA 本地可用性检查；
- 素材按授权下载到本地，输出按策略上传；
- 本地任务不计平台模型费用，但记录用量；
- 断线恢复、取消和敏感文件范围控制。

### 11.3 云端算力

云端算力包括平台托管 GPU 和用户自有云实例。产品必须支持：

- GPU 型号、显存、区域、镜像和实例池；
- ComfyUI/推理容器模板；
- 启动、预热、租约、心跳、扩缩容和闲置回收；
- 运行队列、并发、配额和预算上限；
- 模型缓存和镜像版本；
- 实例费用与任务费用分摊；
- 不健康实例隔离和线路降级。

### 11.4 路由策略

用户可以选择固定线路，也可以选择策略：

- 平衡：综合成功率、价格和等待时间；
- 最低成本：优先本地或已有云实例；
- 最快完成：优先热实例和低队列线路；
- 隐私优先：只使用满足数据驻留策略的线路；
- 固定复现：固定模型、Adapter、Workflow 和 Deployment 约束。

## 12. 资产库

- 所有上传和生成结果进入统一资产库；
- 区分 Blob、Asset 和 AssetVersion；
- 显示来源、派生关系、引用位置、可见范围和删除影响；
- 支持项目、类型、模型、标签、作者和时间筛选；
- 私有、组织、可发布、公开四种范围；
- 有引用的版本不能直接物理删除；
- 发布和 Remix 使用固定版本，不跟随最新版本漂移。

## 13. 任务中心

- 查看 WorkflowRun、Job 和外部 Provider/ComfyUI 任务；
- 显示项目、步骤、模型、线路、Deployment、队列、进度和费用；
- 支持取消、重试、从失败步骤继续和切换线路；
- 展示每次 Attempt 和错误分类；
- 本地 Agent 离线、云实例启动、API 限流有不同状态；
- 任务成功后明确显示内容仍可能等待审核。

## 14. 社区与方法

社区允许发布两类内容：作品快照和工作流快照。

发布快照包含：

- 作品或示例结果；
- WorkflowVersion 或创作参数；
- 模型/Adapter 版本与兼容线路；
- 可公开的 Prompt 和资产；
- 预计成本和复现条件；
- 作者、许可和来源关系。

发布前自动删除 Secret、签名 URL、本地路径、内网地址和私有资产引用。Remix 创建独立项目并保留来源，不修改原作品。

## 15. Agent

Agent 是平台交互方式，不是独立事实源。允许的能力：

- 推荐模型、线路和费用方案；
- 根据目标起草 Prompt 或工作流；
- 解释失败、依赖和项目阻塞；
- 生成漫剧草案和审核摘要；
- 在明确确认后调用生成、采纳或发布工具。

Agent 不能读取 Secret、直接写数据库、自动审批自身输出、跨 Workspace 搜索私有内容或无确认执行高额任务。

## 16. 权限模型

基础角色：Owner、Admin、Producer、Creator、Reviewer、Viewer。最终授权按资源与动作计算，不依赖角色名硬编码。

关键权限：

- 管理 API Secret、Local Agent 和 Cloud Deployment；
- 创建/运行/发布工作流；
- 查看真实供应商成本；
- 批准专业产物和采纳 Take；
- 修改预算、成员与公开范围；
- 查看审计日志和导出数据。

## 17. 非功能需求

- 多租户：所有请求和事件带 Workspace Scope；
- 可靠性：任务幂等、可恢复、可取消、可对账；
- 性能：普通 API P95 < 300 ms，任务提交 P95 < 1 s；
- 可用性：控制面 Beta 目标 99.9%；
- 安全：Secret 加密、最小权限、短期凭据、全量审计；
- 可观测：Request -> Run -> Job -> Attempt -> Usage -> Asset 全链路 Trace；
- 可扩展：新增模型或线路不修改创作领域核心代码；
- 可移植：WorkflowVersion 和 Publication 可导出版本清单；
- 无障碍：键盘操作、清晰焦点，状态不只依赖颜色。

## 18. MVP 验收场景

### 18.1 快速生成

- 用户在不创建复杂项目的情况下生成 4 张图片；
- 同一个图生视频任务可在至少两种执行线路间切换；
- 生成前可见价格，完成后费用和资产可追溯；
- 页面关闭后任务继续，可从任务中心恢复。

### 18.2 工作流

- 用户用步骤视图建立 4 步工作流；
- 同一工作流可切换为画布查看且定义不变；
- 批量运行 10 个 Variant，失败行可单独重试；
- 工作流发布后他人可 Remix 并补齐缺失依赖。

### 18.3 三类执行线路

- API：完成提交、轮询/Webhook、结果入库和费用对账；
- Local ComfyUI：完成配对、依赖检查、运行、断线恢复和结果上传；
- Cloud Compute：完成实例调度、模型缓存、运行、闲置回收和任务成本分摊。

### 18.4 漫剧

- 一集至少包含 3 场、10 个 Units 和多 Take 审核；
- 一个 Shot 因模型限制拆为多个 Units；
- 上游资产变化仅标记相关下游 stale；
- adopted Take 和实际尾帧可追溯；
- 交付包包含视频、参数、资产、审核和费用清单。

## 19. 产品验证重点

工作流交互需要重点验证，而不是预设无限画布一定正确：

1. 用户能否在步骤视图独立建立和修改流程；
2. 哪些真实任务需要分支、合并和拓扑视图；
3. 画布是否提高理解，还是增加拖拽和连线负担；
4. 批量任务是否更适合表格而不是节点图；
5. 模板使用者是否只需要简化表单；
6. 同一工作流在多视图切换时，用户是否保持正确心智模型。

在验证结果出来前，产品称为“工作流编排”，不称为“无限画布产品”。
