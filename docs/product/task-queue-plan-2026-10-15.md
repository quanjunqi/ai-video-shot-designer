## §5 防重演机制（写入本文件，作为开工约束）

1. **IA 归属声明**：任何新增页面/入口，任务卡必须声明归属导航并对照双清单；禁止新功能悬置在无关导航下（本次"预算孤悬"教训）
2. **依赖登记**：本文件 §2 为依赖唯一事实源；开工卡先检查前置，前置未验收不得开工
3. **门禁配套**：前端改动必跑 `npm run gate` + `ui:generate` 同步三清单；覆盖率棘轮 fail-closed
4. **UI 先行**：涉 UI 卡一律 AC-009 设计稿先行评审
5. **验收闭环**：每卡 AC-001 验收清单 → 自检勾对 → PR 附勾对 → 台账回流
