# 国内 AI 图像/视频/音频生成产品「生成 / 创作」页 UX 竞品拆解

> 调研日期：2026-10-10 ｜ 对标项目：漫剧导演工坊（剧本 → 分镜 → 资产 → 视频）
> 方法：web_search + 网页实抓。**每条事实附带实际抓取来源 URL**。无法核实的一律标注「未核实」。
> 重要方法论提醒：**厂商 API 文档 ≠ 网页版 UI**。API 参数只能证明「该能力存在且被平台建模」，不能证明「它出现在首屏/高级设置里」。本报告对二者严格区分标注。

## 0. 先读这一段：本次调研的三个硬约束

1. **绝大多数国内 C 端生成页是 JS 渲染，curl 抓不到 DOM。** 即梦、Liblib、可灵、海螺、通义万相、Vidu、堆友的官网首页抓回来只有 19–334 字符（纯骨架）。因此本报告的「界面事实」主要来自三类可核实来源：**(a) 大厂 LLM 优化文档（可信度最高）**、**(b) 带截图的中文实测教程/横评**、**(c) 官方规则/定价页**。凡属 (b) 类的内容农场（18183、php.cn、17golang 等）我单独降级标注。
2. **php.cn 全站对本环境返回 129 字节空壳**，其大量教程无法核实，我未采信其结论。
3. **部分产品已消亡或退化**：文心一格已停运（见 §8），这对「多模型聚合平台」的长期性是一个直接反例。

## 1. 可灵 AI（Kling，快手）— 事实密度最高

### 1.1 页面布局
- **左右结构**：2025-02 优设横评对三款产品截图对比后明确指出「Sora 的操作界面设计不同于可灵和即梦左右结构。它的输入框则是位于页面正下方」→ 即**即梦与可灵是左右结构（左侧输入/参数、右侧结果）**，Sora 是底部输入。[来源](https://www.uisdc.com/ai-video-14)
- **O1 起新增左侧「大一统」入口**：优设实测记录「进到可灵页面，你就会注意到**左侧新增了一个非常显眼的图标**，用了这个后面那几个界面你基本就用不着了」——即把参考生视频/文生视频/首尾帧/内容增删/风格重绘收敛进单一入口。[来源](https://www.uisdc.com/kling-o1-2)
- **O1 的输入区形态**：「进来以后就会发现**下方的提示词输入框位置集成了非常多的选项**，下方用来切换视频和图片生成的基础操作，比如时间比例等，**上方的几个胶囊按钮主要用来控制输入内容的类型**」。[来源](https://www.uisdc.com/kling-o1-2)
  - → 这是一个**「胶囊（chip）切换输入类型 + 输入框内嵌参数」的复合输入区**，输入类型不是独立表单，而是挂在 prompt 框上。

### 1.2 输入类型 / 参考输入挂载方式（可核实）
- **胶囊按钮即输入类型**：选「图片主体参考」→ 出现 **图片 / 视频 / 主体** 三个输入项，且「当然你可以删除图片或者主体，只用文本操作」；选「首尾帧」→ 同一位置变成**首帧和尾帧**两个槽位。「不过提示词也需要对首尾帧进行标注」。[来源](https://www.uisdc.com/kling-o1-2)
- **@ 素材指代**：文本编辑视频时「你只需要上传需要编辑的视频，然后在提示词输入框输入提示词的时候**在指代素材那里 @ 对应的素材**就行」。[来源](https://www.uisdc.com/kling-o1-2)
- **主体（element）是可复用的命名资产，不是一次性上传**：点添加主体图标 → 右侧弹出主体选择弹窗，官方内置主体可选；也可去「我的主体」创建。「**因为它可以上传多个不同角度的图片**，更大程度的提高角色、道具、场景在视频生成中的一致性」；「你还可以将**多个主体叠加**」。[来源](https://www.uisdc.com/kling-o1-2)
  - API 侧印证主体被建模为一等资产，且明确区分两类：`element_type` 枚举 `video_character_elements`（视频角色主体）与 `multi_image_elements`（多图主体）；参考图带 `role` 属性，枚举 `frontal`（正面参考图）/ `refer`（其他参考图）。[来源：可灵 API 任务查询](https://klingai.com/document-api/api/video/3-0-omni/text-to-video.md)
- **音频/音效是一等输入**：API 中 `type` 枚举含 `image, video, audio, element, voice`；`element.references[].type` 含 `image/video/voice`。即**图片、视频、音色三种模态可共同挂在一个主体上**。[来源](https://klingai.com/document-api/api/video/3-0-omni/text-to-video.md)

### 1.3 参数组织（官方能力矩阵 — 最可信的一手材料）
- **模型×能力的矩阵化表达**：可灵官方在文档中给出完整「能力地图」，同一张表里逐模型打「支持 / 不支持 / 条件支持」。例如「首尾帧」一行：3.0 Turbo **不支持**、3.0 支持、3.0 Omni 支持、O1 支持、2.6「仅 1080P 且仅无声视频」、2.5 Turbo「仅支持 1080P」。[来源：视频能力地图，更新于 2026-05-19](https://klingai.com/document-api/guides/capability-map/video.md)
  - → **这是「不可用参数隐藏/置灰」的权威依据**：能力差异被显式枚举为「不支持/条件支持」，而非让用户试错。
- **参数清单（视频，Kling 3.0）**：`resolution` = 720p / 1080p / 4k；`aspect_ratio` = 16:9 / 9:16 / 1:1；`duration` = 3–15 整数秒；`multi_shot`（是否多镜头，默认 true）；`audio` = native / off；以及回调地址、自定义任务 ID、含水印结果开关。[来源](https://klingai.com/document-api/api/video/3-0-omni/text-to-video.md)
- **多镜头靠 prompt 语法而非独立控件**：`镜头 n, m, words;`（半角分隔），**最多 6 个分镜、最少 1 个，各分镜时长之和必须等于总时长**；且 `multi_shot=false` 时即使写了多镜头格式也不生效。[来源](https://klingai.com/document-api/api/video/3-0-omni/text-to-video.md)
  - → 对本项目极有参考价值：**分镜时长约束被做进了模型契约**，这正好是漫剧分镜的天然形状。
- **图片参数**：`aspect_ratio` 覆盖 `16:9 / 9:16 / 1:1 / 4:3 / 3:4 / 3:2 / 2:3 / 21:9`（3.0 Omni 与 O1 额外支持 `auto`）；分辨率 1K / 2K，3.0 Omni 支持 **4K**。[来源：图片能力地图](https://klingai.com/document-api/guides/capability-map/image.md)
- **组图生成**：Kling Image 3.0 Omni 与 2.1 支持「组图生成」，返回体中用 `group_id` 标记组图分组关系。[来源](https://klingai.com/document-api/guides/capability-map/image.md) 与 [来源](https://klingai.com/document-api/api/video/3-0-omni/text-to-video.md)
- **提示词长度上限**：3072 字符（建议 ≤2500）。[来源](https://klingai.com/document-api/api/video/3-0-omni/text-to-video.md)

### 1.4 提示词辅助
- **可灵在图片和视频生成界面直接接入 DeepSeek-R1 帮你写提示词**；「哪怕只打上去一个字」也能扩写；R1 会生成「主体及其描述、动作，场景和运镜、光影等细节补充」，并把成语（对牛弹琴）、古诗（王维、岳飞《满江红》）、英文诗（泰戈尔）转成可生成的中文场景描述。[来源：量子位实测，经智源社区转载](https://hub.baai.ac.cn/view/44276) ｜ [同期新闻稿](https://www.stcn.com/article/detail/1587540.html)
  - → 这是**「提示词优化 = 站内嵌入第三方 LLM」**范式的早期、可信样本（2025-03）。

### 1.5 结果区
- 可灵 O1 支持**单条视频自由选择 10 秒内时长，并按时长扣灵感值**——优设作者评价「这个对于做视频 Agent 产品以及一些轻度展示场景绝对是重大利好，相当省钱」。[来源](https://www.uisdc.com/kling-o1-2)
- 以「抽卡」为迭代单位：作者实测「第一次修改**抽卡**直到有符合你要求的内容之后再进行第二次修改」。[来源](https://www.uisdc.com/kling-o1-2)
- 结果 URL **30 天后被清理**（API 明确提示「为保障信息安全，生成的图片/视频会在 30 天后被清理，请及时转存」）。[来源](https://klingai.com/document-api/api/video/3-0-omni/text-to-video.md)
  - → 对草稿持久化是硬约束：**平台不保证长期留存，必须落自己的资产库**。

### 1.6 任务 / 队列 / 并发
- **状态机**：`submitted`（已提交）→ `processing`（处理中）→ `succeeded` / `failed`；失败时 `message` 字段「当任务失败时展示失败原因（如触发平台的内容风控等）」。[来源](https://klingai.com/document-api/api/video/3-0-omni/text-to-video.md)
- **并发模型（官方）**：以**账号**为单位，按**模型版本 + 资源包类型（视频/图片）**独立计算，所有 API 密钥共享配额；任务从进入 `submitted` 到完成期间持续占用并发，结束（含失败）后释放；**取生效中同类型资源包的最大并发值**（5 并发 + 10 并发 → 能力 = 10）。**视频/虚拟试穿每任务固定占 1 并发；图片生成并发数 = 参数 `n` 值（n=9 → 占 9 并发）**。超限报错 `code 1303 / "parallel task over resource pack limit"`，官方建议指数退避（初始延迟 ≥1s）+ 任务队列管理。[来源：并发说明](https://klingai.com/document-api/api/get-started/concurrency-rules.md)
- **排队是可感知的真实痛点**：2025-01 的横评作者记录「快手经常出现需要排队的情况，生成可能不慢，但是整体时间过久」。[来源](https://juejin.cn/post/7462390806582657033)
- **会员等级直接换排队优先级**：可灵会员权益明确包含「去专享快速生成通道、1080p 视频生成、去除生成图片、图片/视频去水印、**专享运镜与视频延长**、图片支持画质增强等功能为会员专享功能」。[来源：可灵灵感值规则说明](https://klingai.com/docs/point-policy)

### 1.7 积分 / 费用可见性
- **标准定价 1 元 = 10 灵感值**；「生成动作发生时即扣除对应灵感值；**如生成失败则退回对应灵感值**」；消耗顺序为「剩余有效期短的灵感值优先于剩余有效期长的」。[来源](https://klingai.com/docs/point-policy)
- **灵感值分类与有效期被精细建模**：运营活动值（以活动规则为准）、常规会员权益值（发放起 1 个月）、7 天会员权益值（7 天）、**登录灵感值（每日首次登录发放，当日 24:00:00 清零）**、充值购买值（2 年）。[来源](https://klingai.com/docs/point-policy)
- **余额与明细入口被写进规则**：网页为「可灵AI」网页侧边导航栏 →「灵感值详情」；APP 为「我的」→ 右上角「灵感值」→「明细」。[来源](https://klingai.com/docs/point-policy)
- **API 侧按秒计费、且费用随参数组合跳档**（可核实的一手表）：Kling 3.0 无声 720P 0.6 积分/秒、1080P 0.8、**4K 3.0**；有声未指定音色 720P 0.9 / 1080P 1.2 / 4K 3.0；动作控制 0.9 / 1.2。3.0 Omni「有参考视频 × 有声」1080P 1.2 积分/秒。Kling 2.6 无声仅 0.3 / 0.5。数字人 0.4 / 0.8。对口型按每 5 秒 0.5。文生音效/视频生音效 0.25/次。[来源：基础能力价格-视频](https://klingai.com/document-api/pricing/base/video.md)
  - → **「按秒 + 分辨率 + 有声/无声 + 是否带参考视频 + 是否动作控制」四维乘出来的价签**，是必须能给用户算清的账。
- **计费回执结构**：任务返回 `billing[]`，含 `charge_type`（`cash`/`unit`）、`cash_type`（`balance`/`test_balance`）、`amount`、`currency`（CNY/USD）、`package_type`（video/image/audio）、`list_price`。[来源](https://klingai.com/document-api/api/video/3-0-omni/text-to-video.md)
- **C 端会员价位（第三方实测口径）**：最高档「黑金会员」11079 元/年、每月 26000 灵感值；免费用户每月赠 128 灵感值。[来源：新榜声量通](https://voice.newrank.cn/study/hot/CA22D5C5433A9F69)

### 1.8 模型选择
- 官方模型矩阵（2026-05-19 版）：Kling 3.0 Turbo（性价比）、Kling 3.0（音画同步/主体一致性/多镜头叙事）、Kling 3.0 Omni（全能多模态、有声角色驱动、直出音画和分镜）、Kling O1（大一统、超高一致性）、Kling 2.6（音画同步）、Kling 2.5 Turbo（性价比）。输入模态逐模型不同（3.0 Turbo 仅文本+图片；3.0/3.0 Omni/O1 支持文本+图片+视频）。[来源](https://klingai.com/document-api/guides/capability-map/video.md)
- **跨模型能力降级被显式记录**：优设指出「针对上方视频，选中『多模态编辑』…需注意此时**会变为『可灵 1.6』视频模型进行处理**，处理内容结果会受影响」、「二次编辑当前仅支持可灵 1.6 模型」。[来源](https://www.uisdc.com/ai-video-26)
  - → 反面教材：**静默切换用户未选择的模型版本**是明确的体验缺陷。

### 1.9 未核实项
- 可灵网页版的**画面比例选择器是否用可视化图标**、**随机种子输入框位置**、**生成数量 n 的 UI 呈现**、**快捷键**、**移动端适配细节**：未核实（官网 JS 渲染抓不到，且无带截图的可靠教程覆盖到这一层）。

## 2. Vidu（生数科技）— 「@ 主体」交互的标杆

### 2.1 页面布局
- 未核实（官网 JS 渲染）。但可确认 **Vidu 在参考生视频中，输入 `@` 会自动弹出选择框**。[来源：爱范儿](https://www.ifanr.com/1653577)

### 2.2 提示词区 / 参考输入 — 本次调研最重要的单点发现
- **主体社区（2026-01 上线）为「全球第一个 AI 视频主体社区，一个可分享、可交易、可互动的主体社区」**，把 **运镜、特效、氛围、表演、构图、叙事、风格、场景、招式 八大类型** 打包成「主体库」。[来源](https://www.ifanr.com/1653577)
- **交互即 `@`**：「我们只需要在输入框里 @ 一下，就能调用」。且**可叠加**：「甚至可以像 Claude Skills 那样叠加使用：@镜头 + @氛围 + @特效 + 角色图」。实测组合式提示词如「@雷暴 不止的 @城市废墟，@图1 站在街道上，正对着镜头作出 @癫狂大笑，结合剧烈的 @急摇镜头，营造出强烈的 @恐怖惊悚氛围」。[来源](https://www.ifanr.com/1653577)
- **主体类型的粒度极细**：景别（特写、全景、鸟瞰、360 度展示）、构图（群像对峙、三分构图、荷兰角）、运镜（推、摇、环绕、探针镜头）、表演/表情（癫狂大笑、夸张大眼哭哭）、招式（百花缭乱分身、冰雨术、金钟罩）、氛围/风格/场景。[来源](https://www.ifanr.com/1653577)
- **用户自建主体的创建流程**：「上传 **1-3 张图片**，选择对应的声音，然后确定风格和提示词，就能得到一个**可以重复使用的人物主体**」。[来源](https://www.ifanr.com/1653577)
- **API 侧完全印证并给出上限**：`subjects` 为「图片主体和文字主体」，「图片或文字主体**最多不超过 7 个**」；`name` 必填且「生成时可以通过 `[@name]` 的方式使用，例如：`[@图1]`」；`images` 最多 3 张；`videos` 最多 1 个 5 秒视频（仅 viduq2-pro 支持视频主体）；`voice_id` 音色；`server_id` 为主体 ID，「不传 server_id 时，为临时主体，系统不保存」。另有 `auto_subjects`（智能主体库能力，默认 false）。[来源：参考生视频](https://platform.vidu.cn/docs/reference-to-video.md)
- **运动幅度是显式枚举参数**：`movement_amplitude` 默认 `auto`，可选 `small / medium / large`。[来源](https://platform.vidu.cn/docs/reference-to-video.md)
- **错峰（off-peak）是一个「用时间换积分」的一等交互**：`off_peak=true` 时「**错峰模式消耗的积分更低**」，任务将在 **48 小时内生成，未能完成的任务会被自动取消并返还积分**，也支持手动取消。另有注记「q2、q1、2.0 系列模型在 audio 为 false 时支持错峰任务」。[来源](https://platform.vidu.cn/docs/reference-to-video.md)
  - → 对本项目「积分计费 + 队列」极有借鉴价值：**把排队从惩罚变成折扣选项**。

### 2.3 参数（API 口径）
- `aspect_ratio`：1:1 / 9:16 / 16:9 / 3:4 / 4:3，**外加 `auto`（根据输入图或视频自动推荐）**；`resolution` 1080p；`duration` 5 秒（viduq1）；`seed`（0 或空为随机）；`audio`（音视频直出，含台词和音效）；`bgm`（从预设 BGM 库自动挑选，q2 系列 duration 为 9/10 秒时不生效）；`watermark` + `wm_position`（1 右下/2 左下/3 右上/4 左上）+ `wm_url`（**水印内容可替换为自定义图片**）；`meta_data`（内容标识透传）。[来源](https://platform.vidu.cn/docs/reference-to-video.md)
- **任务状态含排队态**：`created`（创建成功）/ **`queueing`（任务排队中）** / `processing` / `success` / `failed`，另有 `err_code`、`credits`（该任务消耗积分）、`creations[]`（含 `url` / `cover_url` / `watermarked_url`，**24 小时有效期**）。[来源：文生视频](https://platform.vidu.cn/docs/text-to-video.md)
- **图片生成、文生音效、声音复刻、语音合成、数字人（S2）、一键成片类解决方案均在产品矩阵内**（一键生成 AI-MV / 解说剧 / 电商成片 / 视频复刻 / 通用成片、场景模板、模板成片）。[来源：Vidu API 文档索引](https://platform.vidu.cn/docs/llms.txt)

### 2.4 结果区 / 成本

### 3.2 参数与操作（可核实的教程级事实）
- **图片生成路径与参数**：「选择图片生成、**图片4.0**，**比例 9：16，分辨率为高清 2K**」；「输入提示词后**回车**等待图片生成」。[来源：CSDN 实测教程](https://blog.csdn.net/2501_94117113/article/details/155308168)
  - → 可核实：**比例与分辨率是常显参数**；**回车即提交**。
- **数字人生成路径**：选择「数字人」→ 上传角色图片 → **设置音色** → 输入**角色台词**和**动作描述** → 生成 → 下载。「动作描述」示例为「固定镜头，人物身体有轻微的正常晃动，头不要晃，眼睛始终看向正前方镜头」。[来源](https://blog.csdn.net/2501_94117113/article/details/155308168)
  - → 数字人是**独立功能入口**，台词与动作描述为**两个分离的文本域**，而非统一 prompt。
- **多图输入与参考**：即梦图片 4.0 支持「将事先准备好的图**一股脑全部传给即梦 4.0**」；「可以让它参考图片生成新的动作」；支持「参考所给图片的角色与风格，生成 8 组分镜（起承转合），保持角色关键识别点一致」；并指出「三视图最好是以标准站立的姿势，双手自然往下的正视图作为**参考图**」。[来源：优设即梦 4.0 测评](https://www.uisdc.com/jimeng-8)
- **智能参考（3.0 起的核心图片控制功能）**：入口为「选择『图片生成』功能 → **点击输入框区域的『+』号，上传参考图片**」；上传后**必须选择参考模式**——原文强调「必须选择【智能参考】模式（**不要选『结构参考』或『风格参考』**，否则会强绑构图或只传递色调）」；并要求「选择图片模型：必须使用【图片3.0】或更高版本，旧版模型不支持智能参考功能」；再设置**参考强度（默认 50）**，并给出区间经验（<40 自由发挥过多，>70 易僵硬失真，换背景调至 100）。
  - 三大参考维度：**智能参考**（保持姿态/轮廓/空间比例，「启用 OpenPose 骨骼映射，提取 18 点关键关节位置」）、**风格参考**（仅继承色相/纹理/氛围，建议强度 45–65）、**人物长相**（聚焦面部特征，需正面高清特写）。
  - ⚠️ **可信度降级**：此条来自内容农场 18183（2026-08-23），文本有 AI 生成特征（如「启用 OpenPose 骨骼映射，提取 18 点关键关节位置」这类实现细节不太可能来自官方 UI 文案）。**「三种参考模式 + 参考强度滑杆」这一结构性描述与可灵/通用范式自洽，予以采信；具体数值与 OpenPose 技术细节不予采信**。[来源](https://m.18183.com/gonglue/202608/r0vk9c2n.html)
- **首尾帧**：优设指出「即梦和可灵**新版模型不支持首尾帧生成视频，只有旧版模型支持**此功能」（2025-02 时点）。[来源](https://www.uisdc.com/ai-video-14)

## 7. 堆友 D.DESIGN（阿里）— 三栏布局的教科书式描述

- **布局（AI 反应堆 → 经典生图模式）**：

## 14. 综合（SYNTHESIS）

### 14.1 反复出现的设计范式（附采用者）

**范式 A：三区/两区布局 —「左/上输入参数，中/右结果」**
- 明确证据：**可灵、即梦为左右结构**（对照 Sora 底部输入）[UISDC]；**PixVerse「左边为指令操作区，右边为生成的视频区」**[UISDC]；**无界「提示词在文本框、参数在右、图片显示在中间」**[AIGC.cn]；**堆友「左=模型+画面描述、中=预览、右=灵感库+历史」**[淘江湖]；**通义万相「左侧操作台」**[CSDN，降级]。
- **反例（少数派）**：Sora 系「输入框位于页面正下方」[UISDC]；**可灵 O1 起把参数收进「输入框内嵌 + 上方胶囊」**[UISDC]；**即梦首页 2026 已变为对话入口 + 作品流**[实抓]；**腾讯元宝/混元直接在对话框里生成**[大洋网]；**Vidu 参考生视频以 `@` 唤起选择框**（输入框内联）[爱范儿]。
- → **趋势明确：从「三栏表单」向「单一输入区 + 内联胶囊 + @ 引用」收敛。** 对本项目的建议：生成页不要摆三栏大表单，应做「一个主输入区 + 内联 chip」，把模型/比例/时长收进输入区底栏。

**范式 B：能力矩阵 + 不可用即隐藏/置灰**
- 最强一手证据：**可灵官方能力地图**把每个模型 × 每项能力标注为「支持 / 不支持 / 条件支持（如『仅 1080P 且仅无声视频』）」[Kling 官方]。
- 明确的反面教材：**聚合平台 Liblib「只有可灵 3.0 Omni 模型明确支持选择生成尺寸」**——参数面无法统一[新榜]；**可灵「选中多模态编辑后会变为可灵 1.6 模型」**——静默降级[UISDC]；**海螺 Hailuo 2.3「无法选择生成尺寸」且「一次最长 6s」，15s 需生成三次**[新榜]；**即梦「新版模型不支持首尾帧，只有旧版支持」**[UISDC]；**即梦「必须用图片 3.0 或更高版本，旧版不支持智能参考」**[18183，降级]。
- → **这是本项目（execution 网关 + Catalog `capabilities` JSONB）最该做的差异化：每个模型声明 capability，前端据此隐藏/置灰并实时标注单价。**

**范式 C：比例/尺寸用「语义化可视化预设」**
- **无界**：6 个预设 = 1:1 头像图 / 1:2 手机屏幕 / 4:3 文章配图 / 3:4 社交媒体 / 16:9 电脑壁纸 / 9:16 宣传海报，且可自定义 [AIGC.cn]。
- **可灵 API**：比例 8 档（含 21:9 超宽），3.0 Omni/O1 另有 `auto` [Kling 官方]。
- **Vidu API**：`aspect_ratio` 支持 `auto`（依据输入图/视频自动推荐）[Vidu 官方]。
- **即梦**：比例 9:16 + 分辨率「高清 2K」为常显 [CSDN]。
- → 建议：比例选择器用**带图标的预设网格**，并把「按参考图自动」作为选项（Vidu 的 `auto` 是很好的先例）。

**范式 D：「生成数量 / 候选数」有明确默认值与上限**
- **无界**：默认 **4**，可选 **1–20**；结果区**一屏 5 张**，「点击第 5 张自动翻滚」[AIGC.cn]。
- **可灵 API**：图片生成 `n` 值即并发占用数（n=9 → 占 9 并发）[Kling 官方]；组图用 `group_id` 分组 [Kling 官方]。
- **通义万相 / 即梦（2025 口径）**：一次生成 **4 张图片**、消耗 1 额度 [掘金]。
- → 建议：候选数默认 4；生成数量直接参与**并发与积分**计算（可灵把 `n` 计入并发的做法值得照搬）。

**范式 E：「复刻 / 变体」优先于「重抽」**
- **PixVerse 作品详情**：暴露**关键词、种子、纵横比、运动幅度、风格、原始图片** + 「Go Create」二创 [UISDC] — 最完整。
- **堆友「同款拓展」**：基于成图生成同系列（换发型/配饰/衣服）[淘江湖]。
- **星流「做同款」+「查看回放」**：「看人家是怎么设计出来的」[雷科技]。
- **Liblib/星流结果操作**：移除背景 / 擦除 / 编辑元素与文字 / 重新生成，且「**改的是局部，不是从头再抽四张让你赌**」[雷科技]。
- **Vidu 主体库**：命名主体反复 `@` 复用 [爱范儿]。
- → 建议：结果卡 hover 必须给「复刻提示词到输入区 + 详情（种子/参数/原始参考图）+ 局部编辑 + 生成变体」，**详情抽屉要能一键回填全部参数**。

**范式 F：主体 = 可命名、可复用、可多图、可跨任务的一等资产**
- **可灵**：主体 =「我的主体」/官方内置，**多角度图片**建主体，**可多主体叠加**；API `element_type` 区分「视频角色主体」与「多图主体」，参考图分「正面参考图 frontal / 其他参考图 refer」[UISDC] + [Kling 官方]。
- **Vidu**：**主体社区（8 大类，可分享/可交易/可互动）**，上传 **1–3 张图** + 选声音 + 风格 + 提示词 → 可复用主体；API 上限 **7 个主体**、`[@name]` 引用、`server_id` 持久化（不传则临时）[爱范儿] + [Vidu 官方]。
- **即梦**：首页导航一级项就是「**资产 / 主体**」[实抓]。
- **吐司**：一级入口「**参考创作（根据你的参考/角色创建任意视频/图像）**」+「数字分身」[实抓]。
- → **这与本项目 AGENTS.md「项目级角色库是角色身份的唯一事实源」完全同构，且被头部产品验证。** 建议把「主体/角色库」做到生成页一级可 `@`，并支持多主体叠加。

**范式 G：积分可见性 =「生成前可见 + 失败退回 + 明细可查」**
- **可灵**：1 元 = 10 灵感值；**生成动作发生时即扣除，生成失败则退回**；余额明细有明确导航路径；灵感值按有效期分 5 类，**登录灵感值当日 24:00 清零**；API 返回 `billing[]` 结构化账单 [Kling 官方规则]。
- **Vidu**：返回 `credits`（本次消耗积分）；`off_peak` 明示「消耗的积分更低」；失败自动取消并**返还积分** [Vidu 官方]。
- **MOKI**：生成前**弹窗告知总消耗**（30 镜 × 4 积分 = 120 积分）[CSDN]。
- **即梦**：「生成界面选择 Seedance 2.0 VIP，需要消耗 495 积分」——**模型档位即标价** [新榜]。
- **反面**：**OiiOii 全程不显示规格与积分** [新榜]；**Liblib 免费 20 积分/日 → 最新模型用不起** [新榜]；**星流免费 150 点数/日 → 「一日体验卡」** [雷科技]。
- → 建议：**模型选择器每个档位旁直接标「本次预估消耗」**；批量任务（分镜 × N）必须二次确认总价；失败必须自动退回。

### 14.3 2025–2026 年的新变化

1. **生成页「对话化」**。即梦首页首屏已是「你好，今天想要创作什么?」+ `生成 / 画布` 模式 + **`Agent 模式 自动 使用技能`** 开关 [实抓]；腾讯元宝把文生/图生视频放进**对话框** [大洋网]；吐司出现「**设计 Agent：对话即设计**」[实抓]。
2. **「技能 / Skills」范式进入视频生成**。Vidu 把运镜/特效/氛围/表演/构图/叙事/风格/场景/招式**八大类打包为可 `@` 调用的「主体库」**，且可**叠加组合**——被媒体直接类比为 Claude Skills「/ 一下就用」[爱范儿]；可灵有 `Kling Skills` 文档条目 [Kling 官方]; 即梦有 `Agent 模式 自动 使用技能` [实抓]。
3. **提示词优化 = 站内嵌第三方 LLM**。可灵图片与视频生成界面**直接调用 DeepSeek-R1** 扩写/转译提示词（成语、古诗、英文诗皆可），「哪怕只打上去一个字」[智源/量子位]。MiniMax 更把它做成**独立接口 `H3-Context-IR`**「深度理解多模态上下文，并生成结构化、语义更丰富的视频提示词」[MiniMax 官方]。
4. **「多模型聚合」成为独立业态，且价格倒挂**。Liblib「接入了 Seedance、可灵、海螺、PixVerse、通义万相、Vidu 等多个主流的视频生成模型…不用多平台切换」[新榜]；**但海螺接 Seedance 2.0 卖到 3.5 元/秒，比即梦本体贵近 60%**，而 **Liblib 卖可灵 3.0 Omni 只要 0.18 元/秒，比可灵本体更便宜** [新榜]。
5. **按秒计费 + 参数组合跳档成为主流价签**。可灵 API 按秒 × 分辨率(720/1080/**4K**) × 有声无声 × 是否参考视频 × 是否动作控制 [Kling 官方]；一档 4K 直接到 **3.0 积分/秒**（是 720P 无声的 5 倍）。
6. **错峰/低优先级队列被产品化为「折扣」**（Vidu `off_peak`，48h 内出、更省积分、可取消、失败返还）[Vidu 官方]——与「买 VIP 插队」（可灵/即梦）构成两条相反的商业化路径。

### 14.5 对「漫剧导演工坊」的直接可执行建议

1. **生成页不要做三栏大表单。** 采用「**一个主输入区 + 底部内联参数条 + 上方能力胶囊**」（可灵 O1 形态），把模型/比例/时长/数量收进输入区；同时保留「作品流/最近生成」作为次屏而非抢占首屏。[UISDC: 可灵 O1](https://www.uisdc.com/kling-o1-2)
2. **把 `capabilities` 变成 UI 契约**，而不是后端 notes。照抄可灵**能力地图的「支持 / 不支持 / 条件支持」三态表**，前端据此隐藏/置灰参数，并在模型卡上写明条件（如「仅 1080P」「不支持首尾帧」）。这正好落在本项目 execution 网关「禁止硬编码参数映射」的架构上。[Kling 能力地图](https://klingai.com/document-api/guides/capability-map/video.md)
3. **角色/主体库做到一级可 `@`，并支持多主体叠加。** 上传 1–3 张图 + 命名 + 音色 → 持久化主体；生成时 `@角色A @场景B @镜头推`。Vidu 已把「镜头/氛围/特效/招式」都做成可 `@` 词条——**对漫剧而言，「镜头语言词条库」是最值得抄的一招**。[爱范儿: Vidu 主体社区](https://www.ifanr.com/1653577)
4. **积分：模型档位旁直接标单价；批量生成前弹窗确认总额；失败自动退回。** 照 MOKI 的「120 积分确认弹窗」+ 可灵的「失败退回 + billing 回执」。[CSDN: MOKI](https://blog.csdn.net/m0_56144365/article/details/143356820) ｜ [Kling 灵感值规则](https://klingai.com/docs/point-policy)
5. **把「错峰折扣」做成正式选项**（低优先级 = 更少积分 + 明确 SLA + 可取消 + 失败返还），而不是只卖「VIP 插队」。这对成本敏感的漫剧团队是强吸引力。[Vidu off_peak](https://platform.vidu.cn/docs/reference-to-video.md)
6. **结果卡必须能「复刻」。** hover：下载 / 放大 / 变体 / **复刻提示词到输入区** / 重新生成 / 延长 / 生成视频；详情抽屉展示**种子、模型版本、全部参数、原始参考图**并可一键回填。PixVerse 作品详情页是此设计的最完整样本。[UISDC: PixVerse](https://www.uisdc.com/pixverse-magic-brush)
7. **分镜级批量生成要有一等状态面板。** MOKI 的做法（30 个分镜 → 逐镜可重新生成/局部重绘/改字幕音色 → 统一生成视频）就是本项目「分镜 → 视频」的直接参照。[CSDN: MOKI](https://blog.csdn.net/m0_56144365/article/details/143356820)
8. **结果文件 30 天被清理（可灵）/ 24 小时过期（Vidu）** → 必须自动转存到自有资产库，并把「已转存」状态显示给用户。[Kling API](https://klingai.com/document-api/api/video/3-0-omni/text-to-video.md) ｜ [Vidu API](https://platform.vidu.cn/docs/text-to-video.md)
9. **警惕 OiiOii 式全流程黑盒**：全流程引导是对的，但**必须在每一步显示积分预估**，否则会重演「黑盒未明码标价」投诉。[新榜: OiiOii](https://voice.newrank.cn/study/hot/CA22D5C5433A9F69) ｜ [黑猫投诉标题](https://tousu.sina.cn/complaint/view/17400664069)
10. **不要只做入口聚合。** Liblib 的价格优势（0.18 元/秒 vs 可灵本体）是流量来源，但海螺接 Seedance 反而贵 60%、且聚合层参数面不统一（只有可灵 3.0 Omni 能选尺寸）。**聚合的价值必须靠「统一的能力抽象 + 统一的参数面 + 低于原厂的价格」三者同时成立。** [新榜](https://voice.newrank.cn/study/hot/CA22D5C5433A9F69)
