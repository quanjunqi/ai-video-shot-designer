# 生成单元分镜手稿与镜头构图参考图规则

每个生成单元首先必须有文字形式的[生成单元分镜手稿](unit-storyboard-manuscript.md)，并可为该单元生成一张多格导演分镜板；然后才按风险决定是否生成镜头构图参考图。手稿和导演分镜板规划一个单元内的完整镜头组织；`Picture N` 只表示其中某个镜头的计划画面，不是整个单元故事板。镜头构图参考图不是实际生成视频的尾帧，也不应取代上一段实际尾帧图。

## 0. 三层交付顺序

第一层是必需的生成单元分镜手稿：用中文写镜头顺序、局部时间码、景别、机位、站位、动作三态、运镜、声音、参考图选择和镜头衔接。

第二层是单元级导演分镜板：默认一张多格手绘或线稿图片，完整表现当前单元的镜头顺序，仅供导演复核，不上传视频模型。

第三层是按需的镜头构图参考图：只为高风险镜头生成可直接使用的单帧图片 Prompt，并使用官方 `Picture N` 标签。它可以上传视频模型。导演分镜板、俯视站位图和线稿不能替代该单帧图。

## 1. 两层故事板

### 导演规划板

用于人工检查镜头顺序、轴线、人物调度和动作节奏。可使用黑白线稿、简洁手绘、俯视站位图或 3—6 格动作板。规划板可以有箭头、编号和文字，但不要直接作为视频模型唯一参考。

### 模型输入板

用于视频模型图片参考。默认使用最终成片风格的单帧电影感画面，具有清晰的人物、道具、空间和光线。除非用户指定水墨、漫画、赛璐璐或手绘动画，否则不默认使用纯线稿，以免模型把线稿误当成最终风格。

模型输入板默认要求：单一构图、无边框、无分格、无文字、无水印、无拼贴、人物和关键道具清晰可见。

## 2. 单元级导演分镜板格式

导演分镜板必须明确要求多格画布，而不是一张连续电影画面：

```text
[Storyboard Sheet U1｜单元级导演分镜板｜4 panels｜仅供规划复核]
Create one clearly segmented four-panel director storyboard sheet for the complete 12-second generation unit.
Panel 1: ...
Panel 2: ...
Panel 3: ...
Panel 4: ...
Use rough hand-drawn grayscale line art, consistent character silhouettes, arrows for movement, camera side and screen direction, panel numbers only, no dialogue text, no watermark, no photorealistic single-frame composition, no collage of unrelated images.
```

每个分格对应一个文字手稿镜头，分格数与镜头数一致；若动作需要起点/中点/终点，必须拆成独立分格。该图片只用于检查调度和剪辑节奏，不放进 H3 `subject_definitions`，也不作为 `Picture N` 上传。

### 2.1 分镜板参考资产绑定模板

每张单元级导演分镜板 Prompt 前必须先生成一个中文“分镜板参考资产”块，再进入图片模型 Prompt。该块只列当前单元的最小集合：

```text
分镜板参考资产：
人物参考：<Subject N>、<Subject N>——锁定身份、服装、轮廓和各格一致性
场景参考：<Subject N>——锁定空间锚点、透视、路径和主光方向
道具参考：<Subject N>——锁定形状、材质、可见面、持有者和手别
跨段状态参考：上一段实际稳定尾帧图——锁定本单元第一格的真实起始状态；首段写“不适用”
未使用资产：<Subject N>、<Picture N>——当前单元不出镜或会造成空间/动作冲突
```

随后英文 Prompt 必须逐项引用这些资产的职责，例如 `Use the attached character references ...`, `Use the attached environment reference ...`, `Use the attached prop reference ...`；跨段时追加 `Use the supplied previous-unit actual last-frame image as the highest-priority starting-state reference`。若某类资产不适用，明确写 `No additional ... reference is applicable`，不能用泛化的“保持一致”代替。

自动选择规则如下：当前出场角色必选；影响当前镜头空间结构的场景参考必选；被持有、交接、攻击或形成遮挡的道具必选；上一段实际尾帧在跨段单元必选；不出镜角色、未使用道具、其他场景图和与当前动作冲突的 `Picture` 禁止混用。单元级分镜板本身不注册为 `Picture N`，也不上传视频模型。

## 3. 何时生成镜头构图参考图

- 首个生成单元：至少 1 张，锁定开场构图和动作起点。
- 新场景或时间/天气变化：至少 1 张新场景镜头板。
- 景别、机位或摄影机侧明显变化：为新构图生成独立镜头板。
- 多人打斗、追逐、越轴、翻越和道具交接：必须有专用镜头板；必要时分别生成起点和终点板。
- 同一机位的自然动作延续：可复用上一张故事板图，不必重复生成。
- 闪回或风格明显变化：单独生成故事板图并锁定色调和回切点。

参考图数量按单元复杂度决定：简单对白通常无需新增或只需 1 张；普通走位/追逐 1—2 张；多人高速动作 2—3 张。每张图尽量只承担一个镜头或一个连续动作组，避免把互相冲突的构图塞入九宫格。无论图片数量多少，文字分镜手稿都必须保留。

## 4. 动作三态

动作镜头必须在文字中登记：动作起点、动作中点、动作终点。简单动作可用一张中点板；道具交接、摔倒、翻越和夺刀等高风险动作建议使用起点板与终点板，必要时增加中点板。故事板只规划三态，真实跨段状态仍以实际尾帧图为准。

## 5. 镜头构图参考图 Prompt 固定顺序

```text
[Picture N｜镜头构图参考图｜对应镜头与用途]
场景与时间；景别；构图和摄影机位置；角色画面位置与朝向；动作起止；道具状态；透视和空间锚点；光线和色彩；风格；限制项。
```

必须写出相对于摄影机的 `camera left/right`、`foreground/background`、主动作方向、至少两个空间锚点和主光方向。动作交接应写成可观察状态，例如“证物盒从角色 A 的右手进入角色 B 的左手”，不要只写“发生交接”。

## 6. 风格选择

- 写实/影视漫剧：电影感单帧、真实材质、目标成片色彩。
- 二次元/漫画：与最终角色资产一致的赛璐璐或漫画渲染，但仍保持单一清晰构图。
- 水墨/手绘动画：只有用户或剧本明确要求时采用对应笔触；角色和道具轮廓仍需清晰。
- 线稿/手绘规划：保留为导演规划板，不默认传给视频模型。

同一项目的故事板风格必须统一；闪回可以改变色调、颗粒和光线，但不能无意改变角色设计或空间结构。

## 7. 与其他参考图的关系

生成一个单元时，按职责组合输入：角色/场景/道具资产图保持身份与外观；分镜手稿规划镜头组织；必要的镜头构图参考图指导某个镜头的计划构图；上一段实际尾帧图锁定真实首帧状态；上一段尾部视频可选地传递运动惯性。若四者冲突，人物和道具的真实状态以尾帧图优先，构图计划以分镜手稿和构图参考图为准，并在生成设置中记录冲突处理。

## 8. 质量检查

交付前检查：每个单元是否先有多镜头文字分镜手稿；是否有一张分格数匹配的单元级导演分镜板；手稿和分镜板镜头编号是否与 H3 `[Shot N]` 对齐；必要的构图参考图是否为单一可读构图；关键人物和道具是否无遮挡；画面左右与动作轴线是否明确；景别是否与相邻镜头平滑递进；主光和透视是否可复现；导演分镜板是否明确 `multi-panel`，构图参考图是否包含 `no split-screen, no collage, no text, no watermark`；是否错误地把构图参考图称作完整故事板或实际尾帧。
