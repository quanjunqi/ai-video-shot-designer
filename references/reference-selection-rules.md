# 视频生成参考图选择规则

本规则解决的不是“如何制作资产图”，而是“当前镜头到底应该使用哪些图”。Skill 必须按镜头和生成单元自动选择参考图，不得把全部资产无差别塞给模型。

## 1. 先识别五种参考功能

解析每个镜头的需求并标记以下功能：

- 身份功能：需要锁定角色脸部、体型、服装或配饰。
- 空间功能：需要锁定场景结构、固定锚点、时间、天气或主光。
- 道具功能：需要锁定物件外观、持有者、持握手或状态变化。
- 构图功能：需要锁定景别、机位、站位、透视、动作起止或镜头方向。
- 状态功能：需要复现上一段真实生成后的姿势、画面左右、遮挡、道具持有和光线。

一个镜头可以同时命中多个功能，但每种功能只选择解决它的最小图片集合。

## 2. 自动选择决策树

按以下顺序逐镜判断：

1. 是否为首个镜头或发生跨段衔接？是则加入上一段实际稳定尾帧图；首段没有尾帧图，不得虚构。
2. 是否出现新角色、角色近景、服装/伤势变化或身份风险？是则加入对应角色视图；普通远景可使用全身资料卡，面部特写优先面部参考图。
3. 是否进入新场景、改变时间/天气/光线或需要固定空间锚点？是则加入该场景标准空镜；空间复杂时追加俯视布局图用于规划，但不默认作为视频模型输入。
4. 是否出现道具特写、持握、交接、开启/损坏/掉落？是则加入该道具的状态或持握参考图；只要道具在画面中持续可见，就加入外观参考图。
5. 是否发生新构图、景别、机位、轴线、多人调度或高风险动作？是则加入本镜头故事板参考图；自然延续且构图不变时复用上一张故事板图或省略。
6. 是否需要运动趋势？只有平台支持视频续写/视频参考时，才加入上一段尾部视频，并明确其仅用于运动，不用于锁定身份和状态。

## 3. 分段级默认组合

- 首段普通镜头：角色资料图 + 场景空镜 + 本段故事板图；按画面需要追加道具图。
- 后续段同场景自然延续：上一段实际尾帧图 + 发生变化的角色/道具资产 + 复用或更新的故事板图。
- 新场景切换：上一段实际尾帧图（仅当切换动作需要承接）+ 新场景空镜 + 新场景故事板图 + 当前角色/道具资产。
- 道具交接：上一段实际尾帧图 + 交接双方角色图 + 道具持握/状态图 + 交接故事板图。
- 多人打斗或追逐：上一段实际尾帧图 + 主要动作角色全身/姿态图 + 场景锚点图 + 动作故事板图；群众只在身份可辨或会影响站位时加入。
- 闪回：当前闪回角色/道具资产 + 闪回场景空镜 + 闪回故事板图；不把现实时间线尾帧当作闪回构图图，除非剧本明确要求动作连续切入。

## 4. 必选、可选和禁止

每个生成单元的生成设置必须列出三类清单：

```text
必选参考图：不上传会直接破坏身份、状态或构图的图片
可选参考图：平台有余量时用于增强运动或细节
禁止混用：会与当前镜头冲突、造成风格/时间/持有者错误的图片
```

常见禁止混用情况：

- 用故事板参考图代替上一段实际尾帧图。
- 把不同服装、不同伤势或不同时间线的角色图同时作为身份参考。
- 把两个互相冲突的场景空镜同时作为同一镜头空间参考。
- 把俯视站位图或线稿规划板当成最终视频画面风格参考。
- 把上一段视频当作身份和道具状态的唯一来源。

## 5. 参考图优先级和数量控制

当平台有图片数量上限时，按以下顺序保留：

1. 上一段实际尾帧图（跨段状态）；
2. 当前镜头故事板参考图（构图/动作）；
3. 主角色与关键道具图（身份/交互）；
4. 场景空镜（空间/光线）；
5. 次要角色、细节图和上一段视频（增强项）。

默认不超过平台上限；若平台未明确上限，优先控制在 4—8 张，避免参考冲突。每张被选图片都要写出用途，不能只列文件名。若一张图已经解决同一功能，不再追加同功能的冗余图片。

## 6. 输出要求

在每个分段的中文生成设置中增加“参考图选择”字段，按以下格式输出：

```text
参考图选择：
必选：<图像标签>——<解决的连续性问题>
可选：<图像标签>——<增强作用>
禁止混用：<图像标签>——<冲突原因>；没有冲突时写“无”
```

该字段是用户上传素材的操作清单，不复制到 H3 六字段。H3 Prompt 只注册实际需要追踪的标签，并在 `summary` 或 `detailed_description` 中说明故事板图和视频参考的用途。

## 7. 交付前自检

逐段确认：是否选了上一段真实尾帧；是否使用了本段故事板图或明确说明复用；角色视图是否匹配景别；道具图是否匹配当前持有者和状态；场景图是否匹配时间/天气；是否存在相互冲突的参考图；参考图总数是否在平台上限内。
