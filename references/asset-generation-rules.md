# 资产图片生成规则

本规则决定何时生成角色、场景、道具和风格参考图，以及每类图解决什么问题。资产图用于稳定身份、外观、材质和空间；不代替故事板参考图，也不代替跨段实际尾帧图。

## 1. 资产类型判断

先从剧本提取会在两个以上镜头出现、影响连续性或参与动作交互的对象。只为这些对象建立稳定资产；临时群众和一次性背景物可用简化描述。

- 角色资产：身份、脸部特征、体型、服装、发型、配饰、伤势和常用姿态。
- 场景资产：空间结构、固定锚点、时间、天气、主光方向和材质。
- 道具资产：外观、材质、尺寸、持有者、持握手和剧情状态变化。
- 风格资产：画风、镜头质感、色彩、颗粒和渲染方式。只在全片有明确统一风格时建立。

同一资产只分配一个稳定标签和一套核心描述。后续单元沿用原标签，不用同义词重写外观。

## 2. 角色资料包

主角或跨场景角色默认生成一套多视图资料卡：正面全身、左/右 45 度半身、侧面和背面。另按镜头需要生成面部特写、服装/配饰细节和动态姿态图。

- 多视图资料卡用于建立身份，不直接承担某个镜头的构图。
- 对白密集角色可增加表情九宫格；它是表情参考，不是视频镜头输入的默认图片。
- 打斗、奔跑和翻越角色可增加 2—4 张动作姿态图，分别覆盖起势、受力、落地和恢复站姿。
- 视频生成时只选择与当前镜头角度和动作匹配的视图，避免把整张资料卡当成单一构图。
- 服装、发型、伤势、饰品和鞋子必须在资料卡与后续 Prompt 中保持一致。

角色 Prompt 固定包含：用途和标签、身份与年龄段、面部识别点、体型比例、服装层次、发型、配饰、视图/姿态、背景、光线、风格和限制项。资料卡应使用干净背景、完整肢体、均匀光线、无文字和无水印。

## 3. 场景资产包

主要场景默认建立三种互补资产：

1. 标准空镜：宽幅或目标画幅的无人场景，用于锁定整体结构、色彩、天气、时间和主光。
2. 空间布局图：俯视平面图或简洁机位图，用于导演规划固定锚点、人物路线、摄影机侧和轴线；必要时以纯文字站位地图交付。
3. 镜头专用故事板参考图：针对具体镜头锁定景别、机位、站位和动作，不与标准空镜混用。

俯视图是空间规划资料，不是视频模型的默认画面输入。九宫格或六宫格适合人工整理多角度预览，但不应作为复杂镜头的唯一视频参考；模型输入优先使用单一、清晰、无分格的镜头图。

场景 Prompt 必须写出 3—6 个固定锚点（门、窗、柱、楼梯、招牌、车辆等）、主动作轴线、主光方向和不可漂移的空间关系。不同时间或闪回色调应建立独立场景变体标签，避免暖冷风格相互污染。

## 4. 道具资产包

关键道具至少生成外观多视图，并在剧情发生持有者变化、开启/关闭、损坏、掉落或交接时补充状态图。

- 外观图：正面、侧面、顶部或关键结构，固定材质、颜色、尺寸和磨损。
- 持握图：角色用哪只手、握持位置、遮挡程度和相对比例。
- 状态图：关闭/打开、完整/损坏、持有者 A/持有者 B、落地或被抛出等状态。

道具的 `retention_analysis` 必须记录每次易手或状态变化；`state_diff` 只能写剧本实际发生的变化。道具文字、标识和屏幕内容若容易生成错误，默认标记为后期合成。

## 5. 资产 Prompt 统一格式

每项资产单独输出、可直接复制的图片 Prompt，并在标题中写明用途和标签。推荐顺序：

```text
[标签｜资产类型｜用途]
主体/空间描述；视图或状态；构图与比例；光线与色彩；风格；背景；限制项。
```

限制项默认包括 `no text, no watermark`；资料卡还应加入 `consistent proportions, full body visible`；故事板参考图另按 [storyboard-generation-rules.md](storyboard-generation-rules.md) 添加 `no split-screen, no collage`。

## 6. 资产复用检查

交付前确认：主角色视图覆盖当前镜头角度；场景空镜覆盖当前时间和天气；关键道具外观与状态覆盖本段动作；所有单元引用相同标签；没有把资产图、故事板图和实际尾帧图混称。
