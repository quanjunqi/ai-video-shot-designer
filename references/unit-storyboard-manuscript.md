# 生成单元分镜手稿规范

生成单元分镜手稿是每个视频生成单元必需的导演规划文本。它描述一个不超过 15 秒的单元如何由多个镜头组成，供导演复核、参考图选择和 H3 `detailed_description` 对齐；它不是单张图片，也不是需要复制到视频模型的字段。

如果用户需要可视化手稿，还要单独生成“单元级导演分镜板”：一张包含多个有边界分格的手绘/线稿规划图。它表现整个生成单元的镜头顺序，不是某个镜头的电影感构图参考图。

## 1. 与图片参考的职责边界

每个单元先生成分镜手稿，再判断是否需要图片：

- 角色、场景、道具资产图负责稳定身份、外观、材质和空间锚点。
- 生成单元分镜手稿负责镜头顺序、节奏、站位、动作链、轴线和衔接。
- `Picture N` 只表示某一个镜头或连续动作组的镜头构图参考图，不代表整个单元的故事板。
- 上一段实际尾帧图负责跨段真实状态；它优先于计划中的分镜手稿和 `Picture N`。

因此，不是每个镜头都需要生成图片，也不能因为有了 `Picture N` 就省略分镜手稿。

## 2. 单元级组织规则

- 一个 15 秒以内的单元通常包含 2—5 个文字镜头；高强度打斗或快速追逐可减少到 2—4 个镜头，避免一个镜头承载过多不可控动作。
- 每个镜头只承担一个主要叙事动作或一个清晰的动作组，必须有动作起点、过程和终点。
- 镜头局部时间码从 `00:00.000` 开始，递增到单元结束；与 H3 `detailed_description` 中的 `[Shot N]` 和 `At MM:SS.mmm` 一一对应。
- 单元第一镜必须说明初始状态或上一段实际尾帧复现；最后一镜必须形成可截取的稳定交接状态。
- 相邻镜头检查景别递进、视线方向、摄影机侧、主光方向、运动方向和道具持有者；需要越轴时加入中性或高角度桥接镜头。
- 文字手稿使用中文交付，不使用表格，不把导演分析写成模型字段。

## 3. 每个镜头的必填信息

每个镜头至少写出：

- 镜头编号、单元局部时间码、持续时间和叙事功能。
- 景别、摄影机角度、摄影机位置/摄影机侧、构图和透视。
- 人物画面位置、层次、朝向、视线和动作轴线。
- 动作链：起点、过程、终点；说明运动方向、接触关系和落点。
- 道具状态：持有者、手别、可见面、交接前后状态。
- 运镜类型、方向、幅度、速度和停止位置。
- 光线方向、颜色、可见光源和声音/对白。
- 参考图选择：必选、可选、禁止混用；没有必要图片时明确写“无需新增镜头构图参考图”。
- 镜头衔接：本镜如何承接上一镜，尾帧如何交给下一镜。

## 4. 单元级导演分镜板（图片 Prompt）

单元级导演分镜板是给图片模型的规划图 Prompt，不是给视频模型的参考图。默认每个当前交付单元生成 1 张，包含 2—5 个按时间顺序排列的分格；复杂打斗或追逐可使用 3—6 格。每格只表现一个镜头或一个动作节点，并在格内用简短英文编号 `1`、`2`、`3` 标示顺序，不加入对白、长文字、水印或装饰性标题。

导演分镜板 Prompt 必须明确要求：`multi-panel storyboard sheet`, `four clearly separated panels`（按实际镜头数替换）、`same characters and props across all panels`, `panel 1... panel N`, `arrows for movement direction`, `camera side and screen direction`, `rough hand-drawn storyboard line art`, `grayscale or restrained monochrome`, `no photorealistic finish`, `no single full-frame composition`, `no merged action`, `no text except panel numbers`, `no watermark`。

### 分镜板参考资产绑定规则

分镜板不是凭空绘制的抽象动作图。生成 Prompt 时必须在正文中绑定当前单元的最小参考资产，并写清每类资产解决的问题：

- 当前出场角色的角色参考图：锁定脸型、发型、服装、体型、轮廓和角色之间的可辨识差异；只绑定实际出镜或在画面中留下可见影子的角色。
- 影响构图的场景参考图：锁定空间结构、固定锚点、透视关系、可通行路径、画面左右和主光方向；只绑定当前单元真实发生动作的场景区域。
- 当前被持有、交接、攻击或作为遮挡物的道具参考图：锁定形状、材质、颜色、可见面、持有者和手别；没有道具动作时不要为了“完整”加入全局道具图。
- 跨段单元的上一段实际稳定尾帧图：锁定本单元第一格的真实人物位置、朝向、道具持有状态、遮挡和摄影机侧，优先级高于计划性分镜板和构图形容词。

Prompt 中要列出具体标签及用途，不能只写 `same characters and props`。未出镜角色、未使用道具、不会影响当前构图的资产禁止绑定；缺少某类资产时写“该类资产不适用/未提供”，不得虚构图片。资产冲突时按“上一段实际尾帧状态 > 角色/场景/道具资产 > 分镜板风格描述”处理，并在中文生成设置中记录。

这些参考资产只用于让分镜板各格保持身份、空间和道具连续，不把分镜板变成写实成片，也不把分镜板上传为视频模型输入。

导演分镜板每个分格应对应手稿中的一个镜头，依次表现动作起点、过程或终点；分格下方不写模型字段。它只用于导演检查镜头组织、站位、轴线和节奏，不得作为视频模型唯一输入，也不能冒充实际尾帧图。

推荐标题格式：

```text
[Storyboard Sheet U1｜单元级导演分镜板｜4 panels｜仅供规划复核]
Create one clearly segmented 4-panel storyboard sheet for the complete 12-second generation unit ...
Panel 1 ... Panel 4 ...
```

## 5. 何时生成镜头构图参考图

只在构图或空间风险足以影响生成时生成 `Picture N`：

- 单元开场需要锁定首个构图或跨段尾帧复现困难。
- 多人打斗、快速追逐、越轴、翻越、跌倒、夺刀或道具交接。
- 摄影机侧、景别或空间层级发生明显变化，需要中性桥接。
- 新场景、闪回、天气/时间或成片风格变化。
- 复杂尾帧需要明确人物和道具的最终相对位置。

同一机位的简单连续动作只保留文字手稿和单元级分镜板，可以复用已有构图图或不新增单帧图片。必要的 `Picture N` 必须在标题中标明对应镜头编号和用途，不能写成“本单元故事板图”。

## 6. 推荐文字手稿交付格式

```text
生成单元分镜手稿：单元 1
单元时间：00:00.000—00:12.000
本单元叙事目的：……
单元首帧状态：……
单元尾帧状态：……

镜头 1｜00:00.000—00:03.000｜持续 3.0 秒
功能：……
景别与机位：……
构图与站位：……
视线与轴线：……
动作链：起点……；过程……；终点……
道具状态：……
镜头运动：……
光线与声音：……
参考图选择：……
镜头衔接：……

镜头 2｜……
```

手稿中的镜头编号必须与同一单元 H3 中的 `[Shot 1]`、`[Shot 2]` 对齐。导演分镜板的每个分格也必须与这些镜头编号一一对应。手稿可比 H3 更详细，但不能引入剧本没有的剧情事实；仅可补充实现连续性所需的最小走位、停顿、呼吸和视线。
