# MiniMax H3 平台规格单一事实源

本文件是 Skill 内**唯一**定义平台硬约束与经验默认值的地方。其它文档（SKILL.md、output-schema、continuity-workflow、segment-state-schema、director-continuity、reference-selection-rules 等）**不再重复写死这些数值**，需要时引用本文件对应编号；平台升级或要调整默认值时，**只改本文件**即可全局生效，避免多处口径漂移。

## 0. 适用范围与版本锚点

- 目标模型：**MiniMax H3「全能参考 / reference generation」模式**；本 Skill 不适用于其他视频模型。
- 官方文档核对日期：`__________`（首次建立及每次对照官方文档后填写；下方带【平台】标记的项每次必须重新核对）。
- 参数分两类：
  - 【平台】= 平台硬性约束，模型/接口不满足会无法投喂或被拒，升级后优先核对。
  - 【默认】= 本 Skill 的经验推荐值，用于稳定性与复杂度控制，可按项目调整但应在此统一修改。

## 1. 生成单元时长

| 参数 | 取值 | 类型 | 说明 |
| --- | --- | --- | --- |
| `max_unit_duration` | 不超过 **15 秒** | 【平台】 | 单个模型生成单元的硬上限，任何情况不得突破，重叠策略也不例外 |
| `normal_duration_range` | **13.5—15 秒** | 【默认】 | 常规单元建议区间，尽量用满以减少分段数量 |
| `complex_duration_range` | **8—12 秒** | 【默认】 | 多人打斗、快速追逐、频繁道具交接等高漂移风险单元 |
| 时长口径 | 所有单元（含第一段）统一使用上述三档 | 【默认】 | 不再使用孤立的“8—15 秒”等其它区间表述 |

切点优先放在动作停顿、台词结束或情绪落点；不可把一个不可恢复的关键动作拆在切点上。

## 2. 文本量与批次

| 参数 | 取值 | 类型 | 说明 |
| --- | --- | --- | --- |
| `unit_word_count` | **350—500 个英文词 / 单个生成单元** | 【默认】 | 默认复杂度上限，按单元计、不按全片累计；超长先删重复外观/重复连续性句/非必要镜头，不删剧情动作、标签定义或六字段 |
| `batch_unit_count` | 默认一次交付 **1—3 个生成单元** | 【默认】 | 长剧本在用户确认上一批素材后再继续；短剧本也最多先给 3 个；仅当用户明确要求“全部生成单元”才展开全片 |

## 3. 跨段衔接时长

| 参数 | 取值 | 类型 | 说明 |
| --- | --- | --- | --- |
| `stable_tailframe_offset` | 结束前 **0.2—0.5 秒**选稳定帧 | 【默认】 | 不机械取最后一帧；避开运动模糊、闭眼变形、道具不可见帧 |
| `action_overlap_range` | 高风险动作下一段开头复现 **0.3—1.0 秒** | 【默认】 | 后期裁掉重复部分；属于剪辑策略，不因此让单段超过 15 秒 |

## 4. 参考图数量

| 参数 | 取值 | 类型 | 说明 |
| --- | --- | --- | --- |
| `reference_image_count` | 平台未明示上限时控制在 **4—8 张** | 【默认】 | 遵循最小集合，每张写明用途；同一功能一张图已解决就不再追加冗余图；平台有明确上限时以平台为准并按 reference-selection-rules 的优先级裁剪 |

## 5. 六字段固定结构【平台】

每个生成单元严格按以下顺序输出，**不可增删、改名或改序**，且每单元自洽、不依赖用户跨单元拼接：

```text
subject_definitions
summary
retention_analysis
detailed_description
overall_soundscape
non_diegetic_music
```

连续性输入/输出、生成素材、参考图选择、镜头级衔接等元数据一律写在代码块**之前**的中文生成设置中，不得插入六字段。

## 6. 官方标签【平台】

只允许使用四类官方标签，并在 `subject_definitions` 中先定义后引用：

- `<Subject N>`：可复用的可见主体（角色/场景/道具/风格身份）。
- `<Picture N>`：故事板参考图或具体构图面板（计划构图，不是实际尾帧）。
- `<Video N>`：整段视频的剪辑/续写/时序来源；**仅当用户明确提供或要求复用视频时才创建**。
- `<Audio N>`：被复制或参考的音频信号；同上，仅在用户明确提供/要求时创建。

定义行可使用完整或简写句式，二者语义相同：`<Subject 1> is ...`、`<Subject 1> = ...` 或 `<Subject 1> ...`。无论采用哪种句式，标签后都必须有非空的身份/用途描述；建议新产物统一使用 `is` 以提高跨工具可读性。

说话人编号 `(S1)/(S2)…` 与 `<Subject N>` 是两套独立命名空间，不要求数字相同；首次发声时在 `subject_definitions` 或 `summary` 中说明对应关系。

## 7. summary 任务前缀【平台】

`summary` 开头使用与实际输入匹配的官方任务类型前缀，例如：

- `[reference generation]`
- `[reference generation + image reference]`
- `[video editing + audio reuse]`

并在 `summary` 标明全片时间范围、本单元时间范围及与相邻单元的动作衔接；自动估算时长不得写成用户明确指定。

## 8. retention_analysis 保留度枚举【平台】

- 可见内容：`fully_preserved` / `partially_preserved` / `attribute_transfer` / `weak_reference`。
- 音频：`fully_copy` / `partially_copy` / `reference` / `weak_reference`。

逐项列出每个被引用标签出现的镜头与关系，只引用已定义标签。

## 9. detailed_description 格式

| 项 | 规则 | 类型 |
| --- | --- | --- |
| 语言 | 结构描述统一用英文；每个 `[Shot N]` 独立成段，不添加 Visual/Action/Camera 等自定义字段 | 【平台】 |
| 时间码 | 单元内递增，三位小数，格式 `At MM:SS.mmm`（如 `At 00:03.500`）；标题或 summary 同时标全片时间码 | 【默认】 |
| 首镜/尾镜 | 第一镜复现首帧状态（跨段时复现上一段实际尾帧），最后一镜落到可截取的稳定尾帧 | 【默认】 |
| 闪回 | 同段标注 memory/flashback 身份、主时间线全片码、单元局部码、色调、声音桥、回切点；回忆时间码不得覆盖主时间线 | 【默认】 |

## 10. 台词、画面文字与声音标签【平台】

- 台词/歌词：`<d>[Language]原文</d>`，保留原语言、原词与基础标点，不翻译不改写；主体本人发声写 `<Subject N> (Sx)`。
- 画外音：用 `says in an off-screen voiceover` 并说明画面人物嘴唇闭合。
- 跨切镜连续台词：`<scenetrans>`；视频结尾截断：`<cutoff>`。
- 画面中实际可见文字：用英文双引号逐字保留，不把对白自动转成字幕；屏幕/手机/字幕文字默认标记为后期合成。
- `overall_soundscape`：1—4 句英文，环境/动作/非语言人声，不重复对白，无则写 `N/A`。
- `non_diegetic_music`：1—3 句英文，仅角色听不到、观众听到的配乐，无则写 `N/A`；角色能听见的音乐写进 `detailed_description`。

## 11. 内部规划与最终投喂的边界

- `N/S/E/W`、`continuity_in/out`、`shot_handoff_in/out`、`state_diff` 等仅为内部规划字段；最终投喂一律改用 `camera left/right`、`foreground/background` 等自然语言，内部英文字段名不直接面向用户（官方标签与平台模式代码除外）。
- 面向用户的生成设置统一用中文名（连续性输入、连续性输出、生成素材、参考图选择、交接帧等）；英中字段对照与“是否进入六字段”的归属以 [terminology-map.md](terminology-map.md) 为权威表，字段展开细则另见 [segment-state-schema.md](segment-state-schema.md)。

## 12. 一致性优先级（固定顺序）

**首帧/尾帧状态 ＞ 角色与场景参考图 ＞ 连续性台账文字 ＞ 风格形容词。**
上一段视频只传递运动趋势，不能替代尾帧图；故事板参考图只描述计划构图，不能冒充实际生成尾帧。

## 13. 平台升级核对清单

平台版本变化时，逐项核对并更新本表与“官方文档核对日期”：

1. 单段最大时长是否仍为 15 秒；
2. 六字段名称、顺序与必填性；
3. 四类标签语法与 `retention_analysis` 枚举；
4. summary 任务前缀写法；
5. `<d>/<scenetrans>/<cutoff>` 等台词标签；
6. 参考图数量/视频参考上限；
7. 350—500 词等官方建议区间是否调整。
