# MiniMax H3 全能参考模式输出规范

## 角色/场景/道具资产与故事板参考图 Prompt

先根据剧本判断必要的角色、场景、道具、风格和故事板镜头参考图。每项单独输出可复制的英文图片 Prompt，并在标题或括注中写明用途及对应标签。身份/场景图片作为 `<Subject N>` 的来源；故事板镜头参考图作为具体构图、动作面板或首帧计划时建立 `<Picture N>`。不要要求用户额外制作“关键帧 Prompt”。

故事板参考图是“计划中的镜头画面”，用于指导景别、机位、构图、人物站位、动作起止和光线；它不是上一段视频实际生成后的尾帧。跨段连续性仍以实际尾帧图为状态锚点，上一段视频仅作为可选运动参考。

用户明确要求站位地图、机位图或空间预演时，先按 [position-map-schema.md](position-map-schema.md) 输出纯文字站位地图，再输出图片资产 Prompt和 H3 Prompt。站位地图不嵌入六字段代码块。

## 分段优先交付

不要默认生成一个覆盖全片的长 H3 Prompt。先输出一次全局图片资产 Prompt，再把剧本按时间拆成多个独立生成单元；每个单元时长不得超过 15 秒，每个单元各自包含完整六字段结构并可直接复制投喂。

每个单元的六字段代码块之前，用全中文写明：

```text
生成单元：<N>
全片时间线：<全片起止时间>
本段时间线：<本段起止时间，不超过15秒>
连续性输入：<本段首帧必须复现的上一段尾帧或初始状态>
连续性输出：<本段尾帧必须交给下一段的稳定状态>
生成素材：<角色/场景/道具参考图；本段故事板参考图；跨段时追加上一段实际尾帧图；可选上一段视频及其用途>
```

这些衔接说明不放进六字段代码块，避免破坏 MiniMax H3 官方字段结构。

交付时必须明确复制边界：六字段代码块标记为“模型 Prompt，可直接复制”；衔接说明标记为“生成设置（中文，不复制到 H3 Prompt）”。状态、时长和声音交接字段只用于选素材、配置平台和后期剪辑。生成设置不得出现英文解释性文字；官方资产标签可原样保留，平台模式代码可在中文释义后括注。生成素材中必须区分“故事板参考图”和“上一段实际尾帧图”，不能将二者混称。

## 每个分段的六段固定结构

每个分段 H3 Prompt 必须严格按以下顺序，不能增删或改名：

```text
subject_definitions:
...

summary:
[reference generation] ...

retention_analysis:
...

detailed_description:
...

overall_soundscape:
...

non_diegetic_music:
...
```

## 字段语义

`subject_definitions`：逐项定义后文需要独立追踪的主体、图片、视频或音频标签及其参考作用。`<Subject N>` 是可复用的可见内容；`<Picture N>` 是故事板参考图或具体构图面板；跨段实际尾帧图作为状态输入写在生成设置中，除非平台要求把它显式注册为图片标签；`<Video N>` 是整段视频的剪辑/续写/时序来源；`<Audio N>` 是被复制或参考的音频信号。

`summary`：一个英文短段，开头使用与输入素材匹配的官方任务类型前缀，如 `[reference generation]`、`[reference generation + image reference]`、`[video editing + audio reuse]`。当本段使用故事板参考图指导构图时，在正文中说明对应的 `<Picture N>`；不要把故事板参考图误写成上一段实际尾帧。只引用已定义标签；同时写清本段在全片中的时间范围和与相邻单元的动作衔接；不得把自动估算的时长写成用户明确指定。

`retention_analysis`：逐项列出每个引用标签出现的镜头和关系。可见内容使用 `fully_preserved`、`partially_preserved`、`attribute_transfer`、`weak_reference`；音频使用 `fully_copy`、`partially_copy`、`reference`、`weak_reference`。

`detailed_description`：按播放顺序详细描述视觉、主体外观与位置、动作状态变化、镜头运动、台词和同步声音。第一镜在有跨段输入时必须复现上一段实际尾帧状态，同时参考本段故事板图的计划构图；第一段则从故事板参考图和剧本初始状态开始。后续镜头写单元内递增时间码；结尾必须落到可截取的稳定尾帧。每个镜头独立成英文自然段，不添加 `Visual:`、`Action:`、`Camera:` 等自定义字段。发生闪回时，在镜头自然段中明确 `memory/flashback`、全片时间码与单元局部时间码、色调变化、声音桥和返回主时间线的切点；闪回内部时间码仍按当前生成单元递增，不能把回忆时间误当作主时间线时间。单元文字量以 15 秒内可执行为准，不为凑长度扩写无关动作。

复杂动作或追逐的段前生成设置可按镜头重复三行：镜头衔接输入（镜头首帧状态）、镜头衔接输出（镜头尾帧状态）、镜头过渡（具体可执行的摇移、跟拍、切镜或中性桥接）。这些行属于中文生成设置，不复制进 H3 六字段；镜头自然段仍需用英文把同一交接动作写出来。

`overall_soundscape`：1—4句英文，概括全片环境声、物理动作声和非语言人声；不重复对白。无环境声才写 `N/A`。

`non_diegetic_music`：1—3句英文，只描述角色听不到、观众听到的配乐；无配乐写 `N/A`。角色能听见的音乐写在 `detailed_description`。

每个生成单元时长不得超过 15 秒（建议 13.5—15 秒，复杂动作可使用 8—12 秒），并沿用同一标签和参考资产。单元必须在代码块前写明 `continuity_in`、`continuity_out` 和 `generation_inputs`；六字段中的第一镜复现首帧，最后一镜落到尾帧。独立投喂块可使用单元内局部时间码，但标题或 `summary` 必须标明全片时间范围及与相邻单元的对应关系。官方建议的 350—500 词按“单个模型生成单元”计算，不按整部影片累计；超长剧本必须拆分后分别控制每个单元的可执行词量。

## 台词、标签与引用

结构描述统一使用英文；台词和歌词在 `<d>[Language]原文</d>` 中保留原语言、原词和基础标点，不翻译改写。说话人按目标视频实际发声顺序分配稳定 `(S1)`、`(S2)`；主体本人发声写 `<Subject N> (Sx)`。画外音使用 `says in an off-screen voiceover`，并说明画面人物嘴唇闭合。跨切镜连续台词使用 `<scenetrans>`，视频结束截断使用 `<cutoff>`。实际可见文字用英文双引号逐字保留。

## 最终交付

先给出一次角色/场景/道具资产 Prompt 和故事板参考图 Prompt，再按时间顺序给出多个不超过 15 秒的独立六字段 H3 Prompt。每个 Prompt 前提供中文衔接说明；跨段单元必须列出上一段实际尾帧图，首段不虚构尾帧。用户要求时，在每个英文 Prompt 后提供对应中文翻译。不要输出覆盖全片的长 Prompt、分镜表、导演分析或手动拼接说明。
