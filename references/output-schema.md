# MiniMax H3 全能参考模式输出规范

## 角色/场景/道具资产与镜头构图参考图 Prompt

先读取 [asset-generation-rules.md](asset-generation-rules.md)、[storyboard-generation-rules.md](storyboard-generation-rules.md) 和 [unit-storyboard-manuscript.md](unit-storyboard-manuscript.md)，再根据剧本判断必要的角色、场景、道具、风格和镜头构图参考图。每项单独输出可复制的英文图片 Prompt，并在标题或括注中写明用途及对应标签。身份/场景图片作为 `<Subject N>` 的来源；镜头构图参考图作为某个具体镜头的构图、动作面板或首帧计划时建立 `<Picture N>`。不要要求用户额外制作“关键帧 Prompt”。

生成单元分镜手稿是每个单元必需的文字交付，用于规划该单元的完整镜头组织；单元级导演分镜板是可视化的多格规划图；镜头构图参考图只是按需生成的单帧图片辅助。`Picture N` 不是整个单元的故事板，也不是上一段视频实际生成后的尾帧。跨段连续性仍以实际尾帧图为状态锚点，上一段视频仅作为可选运动参考。

用户明确要求站位地图、机位图或空间预演时，先按 [position-map-schema.md](position-map-schema.md) 输出纯文字站位地图，再输出图片资产 Prompt和 H3 Prompt。站位地图不嵌入六字段代码块。

## 分段优先交付

不要默认生成一个覆盖全片的长 H3 Prompt。先输出当前批次（批次数见 [platform-spec.md](platform-spec.md) §2）真正需要的全局图片资产 Prompt，再把剧本按时间拆成独立生成单元；每个单元时长不得超过 15 秒（建议区间见 §1），每个单元各自包含完整六字段结构并可直接复制投喂。只有用户明确要求全部单元时才展开整部剧本。

每个单元的六字段代码块之前，依次输出“本单元分镜手稿”和“单元级导演分镜板 Prompt”，再用全中文写明：

```text
生成单元：<N>
全片时间线：<全片起止时间>
本段时间线：<本段起止时间，不超过15秒>
连续性输入：<本段首帧必须复现的上一段尾帧或初始状态>
连续性输出：<本段尾帧必须交给下一段的稳定状态>
生成素材：<角色/场景/道具参考图；必要的镜头构图参考图；跨段时追加上一段实际尾帧图；可选上一段视频及其用途>
参考图选择：
必选：<图像标签>——<解决的连续性问题>
可选：<图像标签>——<增强作用>
禁止混用：<图像标签>——<冲突原因；无冲突时写“无”>
```

分镜手稿区域使用文字，不使用表格，并且必须包含 2—5 个镜头（复杂动作可为 2—4 个）。每个镜头至少写局部时间码、功能、景别与机位、构图与站位、动作起点/过程/终点、道具状态、运镜、声音、参考图选择和镜头衔接。手稿镜头编号必须与 H3 `detailed_description` 的 `[Shot N]` 对齐；手稿不复制进 H3 六字段。单元级导演分镜板 Prompt 必须明确为多格手绘/线稿规划图，分格数与手稿镜头数一致，并标注“仅供规划复核，不上传视频模型”。

每个“单元级导演分镜板 Prompt”前必须追加以下中文生成设置，且内容必须根据本单元实际出镜情况自动填写：

```text
分镜板参考资产：
人物参考：<本单元出镜角色标签>——锁定身份、服装和轮廓
场景参考：<本单元影响构图的场景标签>——锁定空间锚点、透视和光线
道具参考：<本单元被持有/交接/攻击/遮挡的道具标签>——锁定形状、材质和手别
跨段状态参考：<上一段实际稳定尾帧图>——锁定首格真实状态；首段写“不适用”
未使用资产：<不应上传的标签及原因；无则写“无”>
```

英文 Prompt 必须把上述资产真正用于分镜板，而不是只在标题中列名：角色参考用于各格身份和服装一致，场景参考用于固定锚点、透视、摄影机侧和主光方向，道具参考用于持有者/手别/交接状态，跨段尾帧用于第一格的真实起始状态。分镜板仅是多格导演规划图；它不注册为 `Picture N`，不上传视频模型，也不能替代实际尾帧图或单镜头构图参考图。

参考图选择按 [reference-selection-rules.md](reference-selection-rules.md) 自动判断，不要求用户自行猜测上传哪些图；只列本单元真正需要的最小集合，未使用的全局资产不要重复列出。这些衔接说明不放进六字段代码块，避免破坏 MiniMax H3 官方字段结构。

交付时必须明确复制边界：六字段代码块标记为“模型 Prompt，可直接复制”；衔接说明标记为“生成设置（中文，不复制到 H3 Prompt）”。状态、时长和声音交接字段只用于选素材、配置平台和后期剪辑。生成设置不得出现英文解释性文字；官方资产标签可原样保留，平台模式代码可在中文释义后括注。生成素材中必须区分“单元级导演分镜板”（仅供规划复核）、“镜头构图参考图”（可上传视频模型）和“上一段实际尾帧图”（跨段状态锚点），不能将三者混称。

## 每个分段的六段固定结构

每个分段 H3 Prompt 必须严格按以下顺序，不能增删或改名：

```text
subject_definitions:
...

summary:
[reference generation] ...

retention_analysis:
...

detailed_description:
...

overall_soundscape:
...

non_diegetic_music:
...
```

## 字段语义

`subject_definitions`：逐项定义后文需要独立追踪的主体、图片、视频或音频标签及其参考作用。`<Subject N>` 是可复用的可见内容；`<Picture N>` 是镜头构图参考图或具体构图面板；单元级导演分镜板不注册为 `Picture N`；跨段实际尾帧图作为状态输入写在生成设置中，除非平台要求把它显式注册为图片标签；`<Video N>` 是整段视频的剪辑/续写/时序来源；`<Audio N>` 是被复制或参考的音频信号。

`summary`：一个英文短段，开头使用与输入素材匹配的官方任务类型前缀，如 `[reference generation]`、`[reference generation + image reference]`、`[video editing + audio reuse]`。当本段使用镜头构图参考图指导构图时，在正文中说明对应的 `<Picture N>`；不要把单元级导演分镜板或镜头构图参考图误写成上一段实际尾帧。只引用已定义标签；同时写清本段在全片中的时间范围和与相邻单元的动作衔接；不得把自动估算的时长写成用户明确指定。

`retention_analysis`：逐项列出每个引用标签出现的镜头和关系。可见内容使用 `fully_preserved`、`partially_preserved`、`attribute_transfer`、`weak_reference`；音频使用 `fully_copy`、`partially_copy`、`reference`、`weak_reference`。

`detailed_description`：按播放顺序详细描述视觉、主体外观与位置、动作状态变化、镜头运动、台词和同步声音。第一镜在有跨段输入时必须复现上一段实际尾帧状态，同时参考本段分镜手稿和必要的镜头构图参考图；单元级导演分镜板仅用于规划复核，不写入 H3；第一段则从分镜手稿、构图参考图（如有）和剧本初始状态开始。后续镜头写单元内递增时间码；结尾必须落到可截取的稳定尾帧。每个镜头独立成英文自然段，不添加 `Visual:`、`Action:`、`Camera:` 等自定义字段。发生闪回时，在镜头自然段中明确 `memory/flashback`、全片时间码与单元局部时间码、色调变化、声音桥和返回主时间线的切点；闪回内部时间码仍按当前生成单元递增，不能把回忆时间误当作主时间线时间。单元文字量以 15 秒内可执行为准，不为凑长度扩写无关动作。

复杂动作或追逐的段前生成设置可按镜头重复三行：镜头衔接输入（镜头首帧状态）、镜头衔接输出（镜头尾帧状态）、镜头过渡（具体可执行的摇移、跟拍、切镜或中性桥接）。这些行属于中文生成设置，不复制进 H3 六字段；镜头自然段仍需用英文把同一交接动作写出来。

`overall_soundscape`：1—4句英文，概括全片环境声、物理动作声和非语言人声；不重复对白。无环境声才写 `N/A`。

`non_diegetic_music`：1—3句英文，只描述角色听不到、观众听到的配乐；无配乐写 `N/A`。角色能听见的音乐写在 `detailed_description`。

每个生成单元时长不得超过 15 秒（常规/复杂动作建议区间见 [platform-spec.md](platform-spec.md) §1），并沿用同一标签和参考资产。单元必须在代码块前写明 `continuity_in`、`continuity_out` 和 `generation_inputs`；六字段中的第一镜复现首帧，最后一镜落到尾帧。独立投喂块可使用单元内局部时间码，但标题或 `summary` 必须标明全片时间范围及与相邻单元的对应关系。单单元英文词量上限见 §2；超过时先压缩重复信息或减少非必要镜头，不按整部影片累计。

## 台词、标签与引用

结构描述统一使用英文；台词和歌词在 `<d>[Language]原文</d>` 中保留原语言、原词和基础标点，不翻译改写。说话人按目标视频实际发声顺序分配稳定 `(S1)`、`(S2)`；主体本人发声写 `<Subject N> (Sx)`。画外音使用 `says in an off-screen voiceover`，并说明画面人物嘴唇闭合。跨切镜连续台词使用 `<scenetrans>`，视频结束截断使用 `<cutoff>`。实际可见文字用英文双引号逐字保留。

## 最终交付

先给出当前批次真正需要的角色/场景/道具资产 Prompt，再按单元依次输出必需的文字分镜手稿、单元级导演分镜板 Prompt、必要的镜头构图参考图 Prompt，最后按时间顺序给出当前批次不超过 15 秒的独立六字段 H3 Prompt（批次数见 [platform-spec.md](platform-spec.md) §2）；用户明确要求全部单元时才展开后续批次。导演分镜板 Prompt 是多格手绘/线稿图片 Prompt，仅供规划复核；镜头构图参考图 Prompt 是单帧图片 Prompt，可按参考图选择上传视频模型。每个 Prompt 前提供中文衔接说明和“参考图选择”；跨段单元必须列出上一段实际尾帧图，首段不虚构尾帧。用户要求时，在每个英文 Prompt 后提供对应中文翻译。不要输出覆盖全片的长 Prompt、表格或手动拼接说明。完整端到端范例（资产 Prompt ＋ 分镜手稿 ＋ 导演分镜板 ＋ 对白单元 ＋ 道具交接跨段单元）见 [worked-example.md](worked-example.md)；所有平台硬参数与默认值以 [platform-spec.md](platform-spec.md) 为单一事实源。
